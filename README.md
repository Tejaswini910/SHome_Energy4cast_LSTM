# 🏠 Smart Home Energy Forecasting using LSTM

An end-to-end, production-ready time-series forecasting application that predicts
household electricity consumption for the next **15, 30, 45, and 60 minutes** using
an LSTM neural network, with a full **Streamlit** dashboard for monitoring,
forecasting, analytics, alerts, and energy-saving recommendations.

---

## 1. Project Overview

A smart home system continuously records household electricity consumption.
This application:

- Ingests and cleans historical power consumption data
- Performs exploratory data analysis (daily/weekly/monthly trends, peak hours)
- Trains an LSTM model on the past 24 hours (96 x 15-minute readings) to predict
  future consumption
- Serves multi-horizon forecasts (15/30/45/60 minutes ahead)
- Computes energy analytics (daily/monthly usage, projected cost)
- Raises high-consumption alerts and generates personalized recommendations
- Presents everything in a multi-page Streamlit dashboard

**Example:**

```
Current Consumption: 2.4 kW

Predicted Consumption:
Next 15 min: 2.7 kW
Next 30 min: 2.9 kW
Next 45 min: 3.1 kW
Next 60 min: 2.8 kW
```

## 3. Dataset Description

**Source:** [UCI Individual Household Electric Power Consumption Dataset](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption)

- ~2,075,259 minute-sampled measurements between December 2006 and November 2010
  (nearly 4 years) for a single household in Sceaux, France.
- Original columns: `Date`, `Time`, `Global_active_power`, `Global_reactive_power`,
  `Voltage`, `Global_intensity`, `Sub_metering_1/2/3`.
- Missing values are marked with `?` in the raw file.

This repo includes a lightweight **synthetic sample** at `data/household_power.csv`
(generated by `scripts/generate_sample_data.py`) with a realistic daily/weekly
seasonal pattern, so the app and training pipeline run out-of-the-box without
downloading the full ~20MB archive. To use the real dataset:

1. Download `household_power_consumption.txt` from the UCI link above.
2. Place it at `data/household_power.csv` (semicolon-separated UCI format is
   auto-detected by `src/data_loader.py`).
3. Re-run training (see below).

## 6. Training Steps

```bash
# (Optional) regenerate the bundled sample dataset
python scripts/generate_sample_data.py

# Train the LSTM model (saves models/lstm_model.keras, scaler.joblib, metrics.json)
python -m src.train_model
```

Training uses:
- **Sequence length:** 96 records (past 24 hours at 15-minute intervals)
- **Targets:** next 1/2/3/4 steps ahead (15/30/45/60 minutes)
- **Callbacks:** EarlyStopping, ModelCheckpoint, ReduceLROnPlateau
- **Metrics:** MAE, RMSE, MAPE, R²

## 8. Deployment Steps (Streamlit Community Cloud)

1. Push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io) and create a new app.
3. Select the repo, branch, and set the main file to `app.py`.
4. Add any secrets (e.g. `ENERGY_COST_PER_KWH`) under **App settings → Secrets**
   (these are read via `os.getenv`, so standard `.env`-style keys work).
5. Deploy. The app uses CPU-only TensorFlow (`tensorflow-cpu`) and the bundled
   sample dataset/model, so no GPU, Docker, or Conda environment is required.

> If `models/lstm_model.keras` isn't present in the deployed environment, the
> Forecast/Model Performance pages will prompt you to run training first —
> commit the generated `models/` artifacts to the repo (or train in a CI step)
> before deploying for a fully working demo.
